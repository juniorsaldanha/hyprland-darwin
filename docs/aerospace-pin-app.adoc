// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

New windows of a pinned app are moved to its workspace, and focus follows them.
Running the command again in the same workspace unpins the app.
Running it in another workspace moves the pin there.
Pins are stored outside the config file and survive restarts.

You can also pin from the menu bar icon, or by clicking the `front-app` widget of the bar.
