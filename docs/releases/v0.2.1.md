- **`LICENSE.txt`**: both lines. The licence is still MIT, with unchanged terms.

Nothing changes for you: same licence, same permissions.

## Upgrade

```sh
brew upgrade --cask hyprdarwin
```

> [!IMPORTANT]
> Releases are signed ad hoc (no Apple Developer ID), so macOS asks for **Accessibility** again after an upgrade. In **System Settings → Privacy & Security → Accessibility**, remove HyprDarwin with **−**, add it back, then relaunch. Your config is untouched.

If you're on 0.2.0 and don't want to re-grant Accessibility, you can skip this release: the app hasn't changed.

## Assets

`HyprDarwin-0.2.1.zip` contains `HyprDarwin.app`, the `hypr` CLI, `shell-completion/` (zsh, bash, fish) and `manpage/`. It needs macOS 13 or newer, on Apple Silicon or Intel.
