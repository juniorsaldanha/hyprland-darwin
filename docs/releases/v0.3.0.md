**HyprDarwin 0.3.0** lets you pin an app to a workspace, so its windows always open there.

## New: pin an app to a workspace

Focus a window, then pin its app to the workspace the window is on. From then on, every new window of that app opens on that workspace and focus follows it. Windows already open when HyprDarwin starts are moved there too, without moving focus.

There are three ways to pin:

- **Keybinding**: add `pin-app` to your config. **alt** is the **Option (⌥)** key:

  ```toml
  [mode.main.binding]
      alt-shift-p = 'pin-app'
  ```

- **Bar**: click the app name (the `front-app` widget). This works on every monitor.
- **Menu bar icon**: *Pin <app> to workspace N*. The macOS menu bar is only on the main display.

A toast at the bottom of the screen confirms each pin and unpin.

Running `pin-app` again in the same workspace unpins the app. Running it in another workspace moves the pin there. To unpin any app, even one that isn't running, use **Pinned apps ▸** in the bar's app-name popup or in the menu bar icon.

Apps without a bundle id can be pinned too, by their process name. This covers an app you run straight from its build folder, e.g. with `cargo tauri dev`, so it keeps opening in the same workspace across rebuilds.

Pins are stored in HyprDarwin's preferences, not in your config file, and survive restarts. An `on-window-detected` rule for the same app runs after the pin and can still move the window.

```sh
hypr pin-app                    # toggle the pin for the focused window's app
hypr pin-app --window-id 1234   # …or for a specific window
```

## Upgrade

```sh
brew upgrade --cask hyprdarwin
```

> [!IMPORTANT]
> Releases are signed ad hoc (no Apple Developer ID), so macOS asks for **Accessibility** again after an upgrade. In **System Settings → Privacy & Security → Accessibility**, remove HyprDarwin with **−**, add it back, then relaunch. Your config is untouched.

## Assets

`HyprDarwin-0.3.0.zip` contains `HyprDarwin.app`, the `hypr` CLI, `shell-completion/` (zsh, bash, fish) and `manpage/`. It needs macOS 13 or newer, on Apple Silicon or Intel.
