**HyprDarwin 0.2.0** polishes the bar and the CLI, and fixes the rough edges found since 0.1.0. It also launches the [website and wiki](https://juniorsaldanha.github.io/hyprland-darwin/).

## Highlights

### Shell completion and man pages
`hypr` now has tab completion for **zsh, bash and fish**, and a man page for every command. Homebrew installs both.

```sh
hypr wor<Tab>          # → workspace, workspace-back-and-forth
man hypr-workspace     # the full manual, every flag
```

Completion knows HyprDarwin's own commands too: `init`, `list-plugins` and `new-window-or-open`.

### Bar icons line up with their numbers
Nerd Font icons sat about 3 pt above their labels. The bar now measures where each glyph actually draws and centres it on the label's digits, so every widget sits on one line.

### HyprDarwin, everywhere
Error messages, the version check, the Secure Input notice, the diagnostics window and the command descriptions now say HyprDarwin and point to this repository. The menu bar links to HyprDarwin on GitHub and credits AeroSpace, the tiling core.

### Website and wiki
**[juniorsaldanha.github.io/hyprland-darwin](https://juniorsaldanha.github.io/hyprland-darwin/)** has a live tiling demo and a **[wiki](https://juniorsaldanha.github.io/hyprland-darwin/wiki/)** modelled on Hyprland's. It covers a master tutorial, every config section, writing plugins, the CLI and troubleshooting, with ⌘K search.

## Fixes

- **`hypr` CLI runs on Intel Macs.** 0.1.0 shipped an Apple Silicon-only CLI; it's now universal, like the app.
- **`hypr init`** now applies settings stored as `0`/`1` integers instead of skipping them.
- **`hypr init --wallpaper`** with a missing file now fails before changing anything. It used to apply the settings first.
- **Permissions window** keeps refreshing while hidden (`cmd` + `H`). It no longer shows stale ✓/✗ when it comes back.
- **Config errors stay visible.** The alt+drag warning is added to the diagnostics instead of replacing them.
- **The ⚠ widget menu is readable.** Long reasons wrap instead of making a screen-wide greyed-out menu. Click the reason to copy it, or **Open log** to see the plugin's log.
- **Borders** redraw sharp when a display switches between Retina and non-Retina scaling, and snap back if macOS moves them.
- **Volume widget** keeps updating after switching audio outputs back and forth, even if one switch failed.
- **Building from source** accepts a self-signed certificate even if it isn't marked as trusted.
- **Homebrew cask** uses Homebrew's current syntax, so `brew style` passes.

## Upgrade

```sh
brew upgrade --cask hyprdarwin
```

> [!IMPORTANT]
> Releases are signed ad hoc (no Apple Developer ID), so macOS asks for **Accessibility** again after an upgrade. In **System Settings → Privacy & Security → Accessibility**, remove HyprDarwin with **−**, add it back, then relaunch. Your config is untouched.

New to HyprDarwin? See [Installation](https://juniorsaldanha.github.io/hyprland-darwin/wiki/#/getting-started/installation) and the [master tutorial](https://juniorsaldanha.github.io/hyprland-darwin/wiki/#/getting-started/master-tutorial).

## Assets

`HyprDarwin-0.2.0.zip` contains `HyprDarwin.app`, the `hypr` CLI, `shell-completion/` (zsh, bash, fish) and `manpage/`. It needs macOS 13 or newer, on Apple Silicon or Intel.
