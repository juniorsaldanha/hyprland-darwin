One app instead of five

It forks AeroSpace and builds in what used to need SketchyBar, JankyBorders and a folder of scripts.

⊞

Tiling

AeroSpace's tree tiling, virtual workspaces and real multi-monitor support. No need to disable SIP.

▭

Status bar

One bar per screen with workspace pills, the front app and system widgets. Auto-hide, and a notch panel.

◈

Borders

A gradient ring around the focused window and a dim ring around the rest. Matches JankyBorders.

⚡

Plugins

Any executable speaking JSON lines can be a widget, react to events or run commands.

🖱

Mouse

Focus follows the mouse, and alt + drag moves a window, like Hyprland.

✦

One-command setup

hypr init applies the macOS settings it needs, keeps a backup with undo, and writes a starter config.

Get started

From install to tiling in a minute.

  1. Install with Homebrew (above), or build it: make app-install.
  2. Run hypr init. It sets up macOS and writes ~/.config/hyprland-darwin/config.toml.
  3. Open HyprDarwin and grant Accessibility when the Permissions window asks.
  4. Press alt enter and start tiling.
alt hjklFocus a window
alt shift hjklMove a window
alt 1…0Go to a workspace
alt shift 1…0Send a window to a workspace
alt f / vFullscreen / floating
alt rResize mode
alt + dragMove a window with the mouse

Plain-text config

AeroSpace's TOML plus [bar], [borders] and [notch]. It reloads when you save.

[bar]
    enabled = true
    left  = ['workspaces', 'chevron', 'front-app']
    right = ['cpu', 'ram', 'network', 'volume', 'battery', 'clock']
    workspaces = 'visible'    # 1 │ 2: the workspace on each monitor

[borders]
    enabled = true
    width = 5
    active = 'gradient(0xffff2bd6,0xff22e4ff)'

[mode.main.binding]
    alt-enter = 'new-window-or-open Terminal'
    alt-1 = 'workspace 1'

Plugins in any language

A folder with a manifest and an executable. HyprDarwin runs it, supervises it and draws what it prints.

plugin.toml

api = 1
exec = "./run.sh"
mode = "interval"   # or "stream"
interval = 5
events = ["click", "wake"]

run.sh

#!/bin/sh
pct=$(memory_pressure | awk '/free percentage/ {print 100-$5}')
printf '{"icon":"\\uE266","label":"%s%%"}\n' "$pct"
# {"run": "workspace 2"} runs a command
# {"popup": [...]} adds a click menu
